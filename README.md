# Rahul Voruganti — Portfolio

A modern, cinematic portfolio inspired by peer portfolios — built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Customize your details

Edit **`src/data/profile.ts`** — name, bio, skills, projects, education, achievements, and social links all live in one file.

## Deploy to Vercel

```bash
npm run build
```

Push to GitHub and import the repo on [vercel.com](https://vercel.com). Vercel auto-detects Vite.

## Features

- Animated hero with gradient typography and stat cards
- Infinite marquee name strip
- Glassmorphism cards with scroll animations
- Numbered section headers `[01]`, `[02]`, …
- Project showcase with live / in-development states
- Education timeline
- Contact section with social links
